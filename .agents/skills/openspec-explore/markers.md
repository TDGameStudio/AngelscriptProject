# Marker Vocabulary

One shared marker set — same symbol, same meaning everywhere: explore rounds, `tasks.md` quote blocks, or any other document. Markers are for scannability, never mandatory — plain prose is always acceptable. One marker per line, used sparingly.

- ❔ — an open question awaiting a decision (the user's answer, or to be resolved during implementation)
- 👉 — the recommendation, exactly one where used, always with the reason
- ❗ — a risk, caveat, or constraint — including the assumption that would flip a recommendation
- ⭐ — a heavyweight decision: got (or needs) the full comparison treatment
- ✨ — newly entered: unblocked, or added after the initial write
- 📁 — affected files / paths (exact paths)
- 🔗 — dependency / reference / source (doc §, code path, spec, external repo)
- ✅ — settled or verified: decision locked, or the verification detail itself
- ❌ — dropped: option, path, or approach abandoned, with the reason
- 🔴 — reopened: previously settled or done, then invalidated
- ⏳ — waiting: blocked on research or something external
- 🟢 — landed: the wait above is over, follow-ups unblocked
- 📌 — a pinned fact: looked up (not asked), stated so it can be relied on or vetoed
- 🚫 — out of scope: an explicit boundary — not rejected on merit, just excluded
- 💡 — an insight or implementation hint worth keeping (pattern to reuse, code to mirror)
