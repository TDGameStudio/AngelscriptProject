# Spelled-kind walk, not 107 methods

## Context

Live `Lexer` covers lexing-spec stories. About 26 of 115 `.def` kinds are named. The user asked to plan tests for most kinds without one method per kind.

## Evidence

- `as_token_kinds.def`: 8 empty spellings + 107 spelled rows.
- Empty spellings cannot round-trip: `lex("")` is EOF, not Invalid; Identifier / numeric / string have unbounded text.
- Q27 A: walk non-empty `asGetTokenSpellingAnsi`; keep the 16 contracts; add maximal-munch pairs (`>>` → one `ShiftRight`, `**` → one `Power`).

## Options

| Option | Result |
| --- | --- |
| A. One loop over generated spellings | `.def` edits fail the suite |
| B. 107 `TEST_METHOD`s | Unreadable; easy to skip a row |
| C. Hand-copied 107-pair table | Second source of truth |

## Settled Decision

Option A plus extra pair rows. Do not drop the 16 contract methods. Overlap on `class` / `>>` is intentional.

## Consequences and Flip Condition

If `asGetTokenSpellingAnsi` stops being generated from the `.def`, the walk no longer tracks vocabulary and must be replanned.
