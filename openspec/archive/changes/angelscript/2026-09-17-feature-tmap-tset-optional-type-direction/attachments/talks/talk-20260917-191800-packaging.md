# Talk: one bundled Change

## Context

The selected wave is three parameterized trees. Each is roughly the size of the archived TArray Change.

## Evidence

TArray type-and-direction was one Change and about a hundred-plus new leaves plus generate and corpus. Bundling three trees means several hundred hand-written `.as` files in one Task DAG.

## Options

- One Change per type
- One Change for all three
- TMap alone; TSet + TOptional together

## Settled Decision

One Change holds TMap, TSet, and TOptional. Provenance: draft log R2. The recommendation had been per-type Changes; the user chose the bundle.

## Consequences and Flip Condition

Author groups stay disjoint (no inter-type edges). Generate and corpus join after all three. Flip if parallel author writes collide on shared files or the DAG becomes unprovable — then split along type boundaries without renaming admitted leaves.

2.1 TSet authors     // no edges
3.1 TOptional authors
        ->
4.1 generate
        ->
5.1 spec + corpus
