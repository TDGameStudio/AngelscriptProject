# Talk: which containers this wave covers

## Context

The user asked whether the other containers also need the TArray-style type-axis and direction port after that Change archived.

## Evidence

Old Function Coverage for TMap / TSet / TOptional requires L2 three-direction and L3 type suffixes. Current TMap has typed `&in` only. TSet / TOptional have almost none. SoftObjectPath has no old Function pile. Pointer wrappers use a UObject L3, and TObjectPtr Assign already has three directions. See [old-function-gap.md](../drafts/findings/old-function-gap.md).

## Options

- TMap remaining holes + TSet + TOptional
- TSet + TOptional only
- TMap only
- Include pointer wrappers
- Pointer wrappers first

## Settled Decision

This wave ports TMap remaining holes, TSet, and TOptional. SoftObjectPath and pointer wrappers stay out. Provenance: draft log R1.

## Consequences and Flip Condition

Three parameterized trees share the TArray leaf contract with per-tree type tables. Flip if later evidence shows TMap's existing typed `&in` already satisfies the published host-api requirement — then drop TMap from the bundle.

## Visual

```
TArray          // archived L2/L3
TMap            // half: typed *In, no &out/&inout
TSet            // local int only
TOptional       // local int only
SoftObjectPath  // no old Function pile
pointer wraps   // different L3; out of wave
```
