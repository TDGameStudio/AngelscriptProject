# Separate inventory, source and runtime evidence

Disposition: candidate.

## Reusable Insight

A declared Cartesian grid is an inventory target. Emitting each distinct source proves generation coverage. Executing the intended observation is a separate proof. A common marker cannot prove all arithmetic or lifecycle effects.

## Evidence

The 122 card counts sum to 36,686. PropRebuild declares 90 targets although the inspected ScenarioCases contains only five stored scenarios; the design preserves all 90 as explicit work.

## Boundaries

Use distinct ID/source/category checks and independent source/oracle evidence. Never promote card counts or duplicate sources to proven runtime coverage.

## Application

Apply when authoring and verifying each product and the final catalog completeness test. This attachment is guidance; current requirements and tasks own acceptance.
