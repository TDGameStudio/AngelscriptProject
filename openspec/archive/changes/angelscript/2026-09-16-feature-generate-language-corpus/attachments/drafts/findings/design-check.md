# Pre-creation design check

The current session read the selected draft, its final rounds, all card metadata and the existing ForLoop implementation. It inspected the first three ControlFlow source contracts and representative numerical, registered-funcdef, ABI and property-rebuild contracts against cited Legacy source. This is not a complete per-cell semantic review or a formal Review.

Confirmed findings and dispositions:

1. The old handoff narrowed delivery to three ControlFlow products. The user explicitly corrected it to all 122; every product is now mapped to a task.
2. Generic constraint/compiler and all-under-AngelscriptTestCode prose predates the selected dedicated plugin subclasses. The current design removes those from this delivery.
3. Copied Limit text in unrelated cards and GetExpected examples naming rejects are template defects. Product tasks use actual axis tables and the category partition rather than copying the example blindly.
4. Thirteen cards mention approximation. Q102's int32 decision remains in force, and those observations are explicitly limited. ConvAbi additionally requires external host bits and registration.
5. PropRebuild declares 90 cells from 15 scenarios, but the inspected C++ ScenarioCases has five stored scenarios. The 90-cell target remains; JSON-only variants are new source-generation work, not old execution evidence.
6. Per-card declared counts add to 36,686 for 122 cards. This was a metadata sum, not a fresh execution or full semantic audit. The implementation completeness test must prove actual emitted identities and source category counts.
7. All replacement generator execution evidence currently belongs to the existing ForLoop baseline. No new C++ or generated-AS runtime test ran during Change creation.

The accepted design explicitly scopes this delivery to source generation and its documented observations. Host setup, approximate numeric observations and lifecycle-source variants are not mislabeled as full language-runtime coverage. A discovered contradiction with that accepted boundary requires an evidence-based replan.
