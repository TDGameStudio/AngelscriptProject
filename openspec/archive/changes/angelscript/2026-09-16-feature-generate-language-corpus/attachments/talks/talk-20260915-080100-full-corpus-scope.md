# Deliver all products in one Change

## Context

The early Q39 batch contained three ControlFlow products. A later handoff incorrectly made that batch the whole delivery.

## Evidence

The user explicitly selected all 122 products and ForLoop as baseline on 2026-09-15.

## Options

The selected approach is stated below. The earlier first-batch-only or generic/execution-coupled interpretations are not the current scope.

## Settled Decision

One complete generator Change with per-product tasks; the independent 47-container hand-written design stays separate.

## Consequences

Treating 121 unfinished products as excluded backlog would fail the requested outcome.

## Flip Condition

The user explicitly changes the delivery goal.
