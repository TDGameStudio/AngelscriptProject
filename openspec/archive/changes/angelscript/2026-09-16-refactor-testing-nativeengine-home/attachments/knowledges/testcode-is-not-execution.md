# TestCode file counts are not execution evidence

Disposition: candidate. Origin: angelscript/refactor-testing-nativeengine-home coverage inventory. Not promoted.

## Reusable Insight

Checked-in `.as` TestCode and generated registrations prove catalog identity and bytes. They do not prove frontend acceptance or VM results until a case compiles, links, and executes (or is explicitly rejected) under NativeEngine fixtures.

## Evidence

[Coverage gaps](../drafts/findings/coverage-gaps.md): LanguageSurface and Compiler samples exist, but operator matrices and several execution holes remain. A parallel TestCode language-corpus draft fills directories without running Builder or the VM.

## Boundaries

Does not deny TestCode as the source center. Denies using file or case counts as GREEN for language behavior.

## Application

SourceExecution and VM tasks must record executed oracles. Parser unit tests may stop at syntax. Do not close a language-matrix task because a `.as` container exists.
