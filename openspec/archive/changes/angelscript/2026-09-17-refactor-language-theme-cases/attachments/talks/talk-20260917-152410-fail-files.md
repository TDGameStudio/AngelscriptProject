# Talk: two Fail files

## Context

Negatives had to leave the positive pocket. `Negative` as a FileTag suffix was too vague. The user asked how other corpora name polarity.

## Evidence

Test262 stores polarity in YAML `negative.phase`. libcxx uses `compile.fail` suffixes. This repo's old tree used `Reject/`. P7 still has no compile oracle in the database.

## Options

R1 `*Reject`. R2 `*Fail`. R3 `Reject/` directory. R4 keep one file.

## Settled Decision

Q9=R2 `Fail`. Then: compile-fail and runtime-fail are two files, not two official topics. R20 accepted suffixes `CompileFail` and `RuntimeFail`. `@topic` stays an open label.

## Consequences and Flip Condition

Each theme may have zero, one, or two Fail siblings. Flip if a later Change adds a diagnostic-oracle field and polarity moves back into metadata.
