# Theme pocket, no privileged root

Disposition: candidate

## Reusable Insight

A Language FileTag is a theme pocket. Each VersionTag is one complete case. Parent is optional and only records a real same-program edit. The name `root` has no privilege.

## Evidence

Casting's recorded star was Builder compliance, not Family. Q3 and R20 made several parentless versions the contract.

## Boundaries

Does not apply to the 122 generator products in this Change. Does not make the database compile or run scripts.

## Application

When adding a Language case, start a `@begin` block with no `@parent` unless the body is the same program plus a pointable delta. Do not hang siblings on a dummy parent.
