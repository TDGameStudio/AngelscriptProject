## Why

Hand-authored Language fixtures stack a theme pocket, a privileged `root`, and a forced parent star in one `.as`. The Builder rejects several parentless versions. Negatives sit beside positives. The test Skill still teaches `Get(..., "root")`.

## What Changes

- Parser and Builder admit several parentless VersionTags. `@begin <tag>` opens a case. `root` is an ordinary name.
- Language author files become theme pockets. Compile-fail and runtime-fail are sibling files. Callables use a function header.
- Casting four pockets are lengthened. Other Language leaves keep their current last segment.
- The angelscript-test Skill and the code-database / language-fixtures specs match the new contract.
- Language `.generated.cpp` projections and `root` consumers are regenerated or retargeted.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `angelscript/testing/code-database`: version topology and author grammar.
- `angelscript/testing/language-fixtures`: inventory shape, no required `root`, Fail files.

## Impact

Parent repository: `AngelscriptTestCode/Language/**`, CodeGenTool parsers if they live there, OpenSpec records, `.agents/skills/angelscript-test/**`.
Plugin submodule: `FAngelscriptTestSourceParser`, `FAngelscriptTestCodeBuilder`, Framework tests, `TestCode/Generated/Language/**`, Adoption lookups of `root`.

## Non-goals

122 generator products. asCBuilder diagnostic oracles. Pending Bindings/Containers/World. Treating the database as a compile or execute layer.
