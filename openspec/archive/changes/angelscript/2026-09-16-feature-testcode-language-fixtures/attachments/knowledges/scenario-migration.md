# Migrate scenario meaning and provenance

Disposition: candidate.

## Reusable Insight

Legacy wrappers can combine useful declarations with UFUNCTION/FString/container-host observations. Retain the focused language source, document adaptation and exclusions, and preserve exact annotation/byte proofs where an integration test depends on them.

## Evidence

The inspected code database owns source material; the legacy Foreach and DirectiveInString examples include explicit host dependencies, and Counter consumers assert more than a lookup result.

## Boundaries

This knowledge does not authorize changing language/runtime semantics or deleting isolated test fixtures.

## Application

Use for each container migration and the final admission proof.
