# Directory versus file depends on coverage

Disposition: candidate.

## Reusable Insight

FileTag equals the author path. Whether a live syntax gets `Language/<Theme>/<Slice>.as` or one file depends on how many independent claims remain after thickening, not on a global "every keyword is a directory" or "every theme is one pocket" rule.

## Evidence

First-wave ControlFlow already uses directories. Second-wave flattened six themes to `Language/<Theme>.as`. Auto's 11 local-literal cases become several claims (site, source, qualifier, Fail) once thickened. Mixin can stay a small directory with one family.

## Boundaries

Does not authorize merging a directory into one FileTag by changing discovery. Does not authorize type-matrix padding. Removed syntax is out of this Change.

## Application

Use when planning Language author tasks or naming a new slice under an existing theme directory.
