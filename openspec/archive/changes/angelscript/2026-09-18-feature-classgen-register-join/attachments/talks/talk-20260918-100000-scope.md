# Thin host includes CompileModules

## Context

Register shells exist. ClassGen still cannot materialize UE types. The remaining product choice was how far this Change reaches into the host compile.

## Evidence

AskQuestion Q1 = C. Draft log R2. [join-gap.md](../drafts/findings/join-gap.md) and [thin-host-join.md](../drafts/findings/thin-host-join.md) show Stage1 is not the only dead step.

## Options

- A: host-engine Register + ClassGen proof only; editor `CompileModules` stays dead.
- C: A plus one Builder+Register in `CompileModules` that skips Stage1–4; preprocessor descriptors stay ClassGen input.
- B: Project descriptors become the only ClassGen authority.

## Settled Decision

Q1 = C. Thin host: Builder+Register onto the host Engine, skip the dead compile block, keep preprocessor descriptors.

## Consequences

Editor Initial compile can reach ClassGen. This Change does not replace preprocessor authority and does not join CacheV2 reuse.

## Flip Condition

Switch to B if preprocessor ClassDesc and Builder asType cannot be joined by class name.
