## Architecture reference

Pinned local reference: Clang 22.1.8, `D:/LLVM/llvm-project-22.1.8.src/clang/`.

- `lib/Parse/ParseAST.cpp`: a driver composes Preprocessor, Parser, Sema and ASTConsumer; preprocessing itself does not perform declaration/host-output orchestration.
- `lib/Parse/ParseExpr.cpp`, `lib/Lex/LiteralSupport.cpp`: operator precedence/associativity and explicit literal validation, not arbitrary token skipping or permissive numeric conversion.
- `include/clang/AST/ASTContext.h`, `include/clang/AST/RecursiveASTVisitor.h`, `include/clang/AST/TypeLoc.h`: context-owned nodes, syntax traversal distinct from canonical types, retained source information. This project adds synchronized allocation and worker-local Sema for parallel body fragments; it does not claim that Clang permits arbitrary concurrent mutation of one AST.
