# File count is not Language coverage

Disposition: candidate.

## Reusable Insight

Admitted Language uses theme pockets. Pending uses one program per file and mixes host UClass material. Compare `@begin` cases and host-free theme roots, not raw `.as` counts, before deciding a Language corpus is thin.

## Evidence

Admitted Language: 95 files / 475 cases. Pending/Language: 558 files, of which 124 live under `UClass/` and 258 bodies contain U macros. The six missing host-free themes are 66 files with umacro=0.

## Boundaries

Does not authorize dumping Pending into Language, compiling fixtures, or treating Unreal/Bindings leftovers as core language.

## Application

Use when planning a Language promotion wave or writing the language-fixtures inventory.
