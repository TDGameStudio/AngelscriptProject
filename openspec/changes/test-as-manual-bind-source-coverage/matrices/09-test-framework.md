# Test framework

This matrix plans the script-side conformance and self-hosting corpus for the Runtime-owned reflected AngelScript test protocol. These sources may inherit `UAngelscriptTestSuite`, call `FAngelscriptTest`, and derive advanced commands from `ULatentAutomationCommand`; ordinary `TestSource/Bindings/**` sources may not.

## Recursive-test oracle rules

- Passing AS assertions may verify payload values, but final discovery, pass/fail counts, diagnostics, source locations, phase order, cleanup, cancellation, and registry-generation behavior are C++ observations.
- Expected failure sources use unique messages and deterministic locations so the external oracle can distinguish assertion, exception, timeout, missing expected error, teardown, cleanup, and reload failures.
- HotReload V1/V2/Good/Broken files are separate stored sources; the future runner applies them to the same logical module path in the order named by each task.
- Command tests cover Do, Then, StartWhen, Until, WaitDelay, OnTearDown, OnCleanup, and advanced Before/Update/After plus timeout/client policy.
- World tests cover no-World object ownership, explicit World and GameInstance modes, Actor/Component BeginPlay/tick/destroy, time advancement, and failure cleanup.
- SelfHosted payload duplication is intentional: the subject is the framework contract, not arithmetic, string, or World APIs used to make the outcome observable.
