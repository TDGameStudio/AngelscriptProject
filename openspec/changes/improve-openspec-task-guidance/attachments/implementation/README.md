# implementation/ — 实施工作集

apply 只读这里（外加主制品）。不要把 `../planning/` 整包读进来。

| 文件 | 用途 |
|---|---|
| `task-body-template.md` | 每条 task 的多行字段（Files / Impact / Tests / Verify） |
| `progressive-execution-record.md` | 实施中问题怎么记，不塞进 `tasks.md` |
| `issues.md` | 实施中的问题账本（本阶段从空账本开始） |
| `progress.md` | 实施检查点（按日期追加） |
| `openspec-refactors.md` | 实施中途对 OpenSpec 自身的重构（格式、附录、skill、config） |

卡住才去 `../planning/`，一次一份文件。
