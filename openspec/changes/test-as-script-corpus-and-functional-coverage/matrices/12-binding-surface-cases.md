## Binding File Rules

- Every file cites all contributing provider families and representative Bindings/FunctionLibraries sources in the `Evidence` column.
- Public functions describe user outcomes, not binding phases or test mechanics.
- C++-only route/provenance assertions remain in Bindings tests. AS tests execute the public call and assert its result, mutation, identity, callback, or diagnostic.
- The 17 files are logical teaching families, not replacements for the full 204-file audit or the existing domain corpus.
