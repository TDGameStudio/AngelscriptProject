## API Table Ownership

All Interop and Diagnostics corpus files include verified API usage tables. Interop tables describe public production call patterns and never name test-only fixture types as recommended application APIs. Diagnostics tables identify cleanup, global registration, filesystem, user-interaction, process, editor, and headless limitations.
