## Library File Rules

- Every file has the six-column API table from `corpus-rules.md` and a `Library surface` note naming the published AS namespace/class/receiver plus implicit WorldContext behavior.
- Each executable body composes multiple related calls into a real task and cross-links the dominant domain corpus; it is not an exhaustive wrapper list.
- Native `UKismet*`, `UGameplayStatics`, `UWidgetBlueprintLibrary`, Runtime UClass, and wrapper names appear in `Evidence`, not as user syntax unless the generated AS surface genuinely uses that spelling.
- Asset, input-device, LocalPlayer, editor, RHI, async, and streaming requirements remain explicit and do not weaken pure/default-headless assertions.
- BPLIB-20 is an audit gate, not permission to create `MiscLibraries.as`; every newly discovered stable workflow is assigned a meaningful file/row or a specific non-corpus disposition before implementation closes.
