# Historical Records

Everything below this directory is retained evidence, not current normative or
execution authority. Historical files are immutable snapshots and may contain
superseded plans, rejected candidates, stale status wording and links that were
valid at the time of capture.

Use `index.md` to locate the original path, hash and current replacement. Do not
edit a historical snapshot to make it agree with later implementation; record the
new truth in the current root documents instead.
